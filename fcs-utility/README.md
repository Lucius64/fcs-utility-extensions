# fcs-utility


## Bugfixes

* Fixes an issue where an exception is thrown when attempting to open the context menu for an instance reference.
* Fixes an issue where the dialogue score calculation doesn't match between FCS and the game.

## Features

* Enable inputs for the paths of dependent mods in the file properties.
* Add `Add Missing Fields` to the context menu in the conversation window.
* The maximum value for both the dialogue condition and the dialogue effect will be 10 million.
* Supports adding values to `EventTriggerEnum` and `DialogActionEnum`.
* Editing dialogue conditions now supports Undo and Redo.
